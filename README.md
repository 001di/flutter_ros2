# my_app

Flutter-проект: авторизация, регистрация и главный экран. Без Firebase.
Пользователи хранятся в памяти (`AuthService`), после перезапуска сбрасываются.

Тестовый вход: логин `admin`, пароль `1234`.

## Запуск
1. Установите Flutter SDK.
2. В папке проекта выполните:
   flutter create .
   flutter pub get
   flutter run

(`flutter create .` создаст папки android/ios/web, не затрагивая lib/ и pubspec.yaml.)
